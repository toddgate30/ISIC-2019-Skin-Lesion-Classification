# Start of Training
## Project Goal
My goal for this project is two-fold. First, I want to train an effective model using the ISIC 2019 Skin Lesion Images for Classification. Second, I want to use this dataset of a case study of how Online Batch Selection methods can enhance training. For reference, I have become very familiar with Onlie Batch Selection Methods in my research with Dr. Miller at BYU Delta Labs.

## Initial Setup
I have created this repo with lots of room to grow. My plan is to make it possible to specify all desired hyperparameters in the config file and have the repo malleable enough to make the necessary adjustment for the given test. Furthermore, I hope to make this a great template pipeline for my later ML projects

## Initial Results
On Friday, July 24th, 2026, I started testing the pipeline on the ISIC data. Once I got everything in working order, it was clear that the data imbalance is causing the training to lag. I decided to start using a weighted cross entropy function to counteract the class imbalance. The model sees much slower validation and train accuracy than before, but that is likely because Melonoma was about half the data set and was probably learned quickly. Without class imbalance, the model would start to overtrain and not get above 70% in validation accuracy while getting over 90% in train accuracy. With class imbalance, we now see validation accuracy achieve about 84% but the model is still overfitting.

## Adjusting Data transforms.
I've adjusted the data transforms to include rotations, flips, and color jitter. The color jitter helped but not very much. The model is definitely still over fitting. The images appear to have many different hues to them, so I probably need more than random color jitter. The optimal rotation that I've found is actually 10 degrees, which surpises me. I wonder if it has to do with the aspect ratio. Most images are about 4:3 but we shrink them to 1:1. I'm considering other options like cropping, zooming, and/or padding. I imagine that different rotations will do better with these, so I will likely do a grid search. First, I'm going to attempt online batch selection methods and see what that can do.
