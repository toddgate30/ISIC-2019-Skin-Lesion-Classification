# Project Details
This is a personal project to create a model capable of classifying skin lesions. Data comes from the [ISIC 2019 Skin Lesion images for classification](https://www.kaggle.com/datasets/0a8462d6e856f4540465cfd7667c0019401f78ebd5746738b69dd3a339d72942) dataset on Kaggle. 

# Results and Tests
All runs are recorded to Weights and Biases. Follow these links to see the [initial parameter fine tuning](https://wandb.ai/toddgate30-byu/ISIC_Initial_Runs) (just starting the project) and the [introduction of Online Batch Selection methods](https://wandb.ai/toddgate30-byu/ISIC_Online-Batch-Selection). Reports in the folder /reports/ show qualitative data of my progress in modeling the data, including what has and hasn't work and what I intend to attempt.
